# Anime Tower Defense — design doc site

Single-file site for the game design doc. No build step, no external assets.

Files:
- `index.html` — the whole site, built from `ANIME-TD-GAME-DESIGN-DOC.md` (Nov 27, 2026)
- `ANIME-TD-GAME-DESIGN-DOC.md` — the source doc, written from Game Director Jeffee123's plan

## Put it on GitHub Pages

1. Create an empty public repo on GitHub (suggested name: `anime-td-design-doc`).
2. Push both files to the repo's main branch.
3. Repo Settings, Pages, Source: Deploy from a branch, Branch: main, Folder: / (root). Save.
4. Share the Pages URL with Jeffee123 and new team members.

Nothing in the page invents facts: the final game name, summon chances, launch scope and the other open decisions are listed as undecided, exactly as in the doc.
